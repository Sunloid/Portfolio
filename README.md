# Haider Rizavi Portfolio

A dependency-free GitHub Pages portfolio. Upload the **contents** of this folder to a GitHub repository, then turn on GitHub Pages in the repository settings. `index.html` is the terminal-first entry page; `portfolio.html` is the visual portfolio (reachable from the terminal via the `uiux` command).

## Editing it later

- Edit `app.js` to change project cards, terminal links, and contact details. The `portfolio` object at the top contains the items you will update most often.
- Edit `index.html` for page wording, sections, and layout order.
- Edit `styles.css` for colours, typography, and spacing. The orange/black colour values are at the top of the file.
- Replace `assets/Haider_Rizavi_Resume.pdf` when your resume changes, keeping the same filename so the links continue to work.

## GitHub Pages setup

1. Create a new GitHub repository (for example, `portfolio`).
2. Upload all files and folders in this directory to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. GitHub will provide your public URL after it deploys.

No build step or npm install is required.
